Teslemetry упрощает доступ к вашим продуктам Tesla, предоставляет данные в реальном времени от ваших автомобилей Tesla и интегрирует это в такие платформы, как Homey.

Управляйте своими автомобилями с помощью настроек климата, управления зарядкой, функций безопасности (блокировка/разблокировка, режим охраны) и многого другого. Мониторьте энергосайты с данными о потоке мощности в реальном времени и управлением режимом работы. Отслеживайте статус зарядки и использование энергии Wall Connector. Все данные автомобиля обновляются в реальном времени с помощью Fleet Telemetry без необходимости опросов.

Чтобы начать, вам понадобится аккаунт Teslemetry с активной подпиской. Войдите на teslemetry.com/console и настройте систему. Затем установите это приложение на свой Homey и добавьте свои продукты Tesla через мастер подключения с использованием аутентификации OAuth.

Использование энергии Wall Connector отслеживается по умолчанию и отображается на энергетической панели управления Homey. Поскольку API Tesla сообщает об энергии только после завершения сеанса зарядки, данные о потреблении энергии не будут обновляться в реальном времени во время зарядки. Для данных о локальной энергии в реальном времени рекомендуется использовать приложение "Tesla Power Connect". Если вы используете оба приложения, вы можете исключить устройство Teslemetry из энергетической панели управления в настройках энергопотребления устройства, чтобы избежать двойного учета.

Устаревшие автомобили, которые не поддерживают Fleet Telemetry, в настоящее время не поддерживаются этим приложением.
